# Wood Bowl

Team manager médiéval-fantastique façon « Bol de Bois », entre amis.
Matchs simulés, gazette « L'Écho du Gourdin », cartes de joueurs années 80.

Jeu privé et non commercial.

## Fichiers

- `index.html` : la page de l'appli
- `moteur.js`, `legendes.js`, `carriere.js` : les règles et la simulation des matchs
- `gazette.js`, `gazette2.js` : la rédaction de la gazette
- `son.js` : musiques et bruitages
- `jeu.js`, `style.css` : l'interface
- `manifest.webmanifest`, `sw.js`, `icones/` : l'appli installable (téléphone et ordinateur)
- `img/`, `mus/` : portraits, logos, musiques
